我们每天都在处理复杂的信息。写程序如此，写文章也如此。真正困难的，往往是把事情想明白，然后用尽可能少的东西表达出来。

这篇文章也是 Editorial 的排版样本：长标题、嵌套目录、代码、表格和图片都放在真实的阅读场景里。

## 先让内容站稳

简洁不是删掉一切，而是为重要的东西安排恰当的位置。一篇文章应该从标题开始，让读者知道接下来会遇见什么。

> 让文字有呼吸的空间，也让思考有停顿的地方。

### 长文的节奏

每段只讨论一个主要观点。必要的时候，使用标题来整理思路，而不是让每句话都变成口号。

- 标题给出方向。
- 段落展开观点。
- 例子让抽象的判断变得具体。

### 链接与键盘

试试用 Tab 键走过导航、外观切换和[这条正文链接](https://valaxy.site)。清晰的焦点是阅读体验的一部分。

## 代码也需要留白

下面是一段普通 TypeScript。代码块保留复制按钮、语法高亮和水平滚动。

```ts
interface Note {
  title: string
  published: boolean
}

const notes: Note[] = [
  { title: '保持好奇', published: true },
  { title: '留一点空白', published: false },
]

const published = notes.filter(note => note.published)
console.log(published.map(note => note.title).join(', '))
const intentionallyLongLine = 'A long code line should scroll inside the code block without stretching the article or the mobile viewport.'
```

正文中的 `usePostList()` 使用等宽字体；文章内容仍然使用普通 Markdown，不需要为了迁就主题改变写作方式。

## 表格与图像

| 场景                 | 处理方式             | 希望读者感受到什么       |
| -------------------- | -------------------- | ------------------------ |
| 桌面阅读             | 正文与目录分栏       | 方向清晰，随时回看       |
| 手机阅读             | 目录收进可折叠区域   | 按需展开，专注当前段落   |
| 深夜阅读             | 炭黑背景与柔和文字   | 有层次，同时避免过强对比 |
| 非常宽的表格列与代码 | 在内容区域内水平滚动 | 不影响整页布局           |

## 慢慢记录

维护个人博客，可能是为数不多能自己控制节奏的事情。不必追逐每一个热点，也不必为了填满首页而写作。

留下一些真实的问题、试过的办法和此刻的判断。时间过去以后，我们可以回来看看，哪些想法留下来了。
